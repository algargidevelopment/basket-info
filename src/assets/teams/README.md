# Escudos de equipos

Los originales se obtuvieron de los escudos mostrados en el [directorio oficial de equipos de ACB](https://acb.com/es/liga/equipos). La lista de participantes corresponde a la temporada 2026/27. Para reutilizarlos, importa cada archivo desde `src/assets/teams/` o crea un mapa de imports por slug.

Los escudos de Euroliga están en [`euroleague/`](./euroleague/), con un índice propio para distinguir los recursos de cada competición.
